#XOR Neural Network in CC言語のみ
（標準ライブラリと math.h）でスクラッチ実装された、シンプルな多層パーセプトロン（MLP）による XOR（排他的論理和） の学習プログラムです。外部ライブラリを一切使用せず、バックプロパゲーション（誤差逆伝播法）のアルゴリズムをゼロから理解・検証できるように構築されています。
概要単なる線形分離不可能な問題であるXORを解くために、入力層（2ノード） - 隠れ層（2ノード） - 出力層（1ノード） の3層構造ネットワークを採用しています。
活性化関数: シグモイド関数 (sigmoid)学習手法: 確率的勾配降下法（SGD）に基づくバックプロパゲーション学習データ: XORの真理値表（4パターン）コードの主な仕様パラメータ・要素設定値 / 内容学習率 (lr)0.5エポック数 (epochs)20,000重みの初期化-0.5 から 0.5 の範囲の擬似乱数 (rand())誤差関数2乗誤差 (0.5 * err * err)動作環境Cコンパイラ（GCC、Clang、MSVCなど）math.h をリンクできる環境（Linux/macOSの場合は -lm オプションが必要な場合があります）
ビルドと実行方法1. コンパイルターミナル（コマンドプロンプト）を開き、ソースコードを保存したファイル（例: main.c）があるディレクトリで以下のコマンドを実行します。Bashgcc main.c -o xor_nn -lm
2. 実行Bash./xor_nn
実行結果のイメージ学習が進むにつれて「Total Loss（総誤差）」が徐々に小さくなり、最終的な検証フェーズで次のようにXORの真理値表を正しく分類できるようになります。

入力: [0, 0] -> 予測: 0.0231 (目標: 0) -> 二値分類結果: 0
入力: [0, 1] -> 予測: 0.9754 (目標: 1) -> 二値分類結果: 1
入力: [1, 0] -> 予測: 0.9749 (目標: 1) -> 二値分類結果: 1
入力: [1, 1] -> 予測: 0.0289 (目標: 0) -> 二値分類結果: 0
プログラムの構造活性化関数とその微分:double sigmoid(double x): 入力を $0 \sim 1$ の範囲に写像します。double sigmoid_derivative(double y): シグモイドの出力値 $y$ を用いて勾配を計算します。順伝播（Forward Propagation）:入力層から隠れ層、隠れ層から出力層へとシグナルを伝播させ、予測値を出力します。
逆伝播（Backpropagation）:目標値と予測値の誤差から出力層・隠れ層のデルタ（勾配）を算出し、連鎖律（チェーンルール）に基づいて重みとバイアスを逆向きに更新します。検証フェーズ:学習済みの重みとバイアスを用いて、すべてのXORパターンの予測精度を出力します。
